# SilencePolar 3.4.9 (Minecraft 26.2 Fabric)

## Requirements
- Windows
- Minecraft 26.2 (Fabric)
- Java 25

## How to Use
1. Extract the zip file into a folder.
2. Run `Polar-Manager.exe`.
3. Click **Install / Repair** (first time only):
   - If asked for Java, select `bin\java.exe` inside your **Java 25** folder.
   - Select your Minecraft instance folder (or its `mods` folder) and click **Open**.
4. Click **Local Server** (Connection indicator turns green).
5. Click **Start server** (Local server indicator turns green).
6. Launch Minecraft 26.2 (Fabric) using the same Java 25.

> To switch back to the original server, click **Polar Server**, stop the local server, and restart Minecraft.
